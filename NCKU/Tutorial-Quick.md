## A. Paradigms（選武器）

| 武器 | 是什麼 | 什麼時候 |
|---|---|---|
| 暴力 | 把所有可能枚舉完 | n 很小，或題目就是要你枚舉 |
| 貪心 | 每步選當下最好，且不會後悔 | 排序後就能決定；假貪心很常見 |
| 搜尋 | DFS/回溯：走一步、不行就退 | 要找一組符合條件的狀態 |
| DP | 小問題一直重複算 → memo 起來 | 要最優或計數，且子問題重疊 |
| 圖搜 | 狀態當點、轉移當邊 | BFS=最少步；Dijkstra=有權重 → [Dijkstra.md](../Algorithms/Graph/Dijkstra.md) |
| 模擬 | 照規則一步步做 | 沒有隱藏算法，I 那種 |

口訣：n 小→暴力；當下最好且不後悔→貪心；重複小問題→DP；轉移像走路→圖。

## B. Techniques：座標壓縮

值很大（1e9）但個數不多（1e5）：排序去重，每個值換成排名 `1..k`。

之後 BIT / 線段樹 / 陣列才能開得下。順序關係還在，只是數字變小。

PDF **H Hamburger**：時間 `li,ri,ql,qr ≤ 1e9` → 先壓成排名再處理。

```
vals = 所有出現過的時間
sort + unique
rank[x] = lower_bound(vals, x) 的下標
```

## C. DP 全套（Top-down）

### 固定模板

```
f(state):
    if 到底 / 不合法: return base
    if memo[state] 算過: return 它
    ans = 用更小的 f(...) 拼起來
    memo[state] = ans
    return ans
```

暴力樹上同一個 `state` 被問很多次 → 貼便利貼。這就是 DP。

---

### 1. 基礎

DP = 重疊的小問題 + 用小的拼大的。

- **state**：現在卡在哪（還需要記住什麼）
- **transition**：這一步做什麼決策
- **base**：不用再問別人的情況

這份筆記只寫 Top-down（搜尋 + memo）。Bottom-up 之後再補。

---

### 2. 1D：`f(i)`

掛在「位置 i」。

- 前綴型：`f(i)` = 只用前 i 個（不一定用 i）
- 結尾型：`f(i)` = **必須以 i 結尾**
- 選/不選：`f(i) = combine(不選 i, 選 i)`
- 最優用 min/max；計數用加總

---

### 3. 2D：`f(i, j)`

兩個參數。常見：格子 `(r,c)`、兩個序列下標、或「位置 + 額外記憶」。

格子往右/往下：`f(r,c) = f(r-1,c) 和 f(r,c-1) 拼起來`。  
邊界：第一列/第一行要先定好。

---

### 4. 背包：`f(i, w)`

考慮到第 i 件、容量還剩 w。

| 種類 | 意思 |
|---|---|
| 0/1 | 這件最多一次：拿或不拿 |
| 完全 | 這件能再拿：拿了仍停在 i |
| bounded | 這件最多拿 `cnt` 次（先知道有這號） |

問最大價值 → max；問幾種湊法 → 加總。  
「價值導向 / 重量導向」只是問法不同，state 還是 `(i,w)`。

---

### 5. 序列 / 子序列

從陣列挑（不必連續），常加限制：遞增、交替升降、計數。

- LIS：`f(i)` = 以 i 結尾的最長遞增
- 計數 / 最優：同一套 state，改加總或 min/max
- zigzag / 交替：還要記住「下一個要比 prev 高還是低」

對上 A：`f(pos, prev, higher)`，見 [A.cpp](A.cpp)。  
n 大時後面會用資料結構加速轉移，先求 state 對。

---

### 6. 狀態設計

state **只記「下一步決策還需要的資訊」**。多記會爆，少記會錯。

從「最後一步做了什麼」反推要記什麼。能刪的維度就刪。  
Top-down 通常從大問題往小問（backward 想、recursive 走）。

---

### 7. 計數 DP

問「有幾種」，不是最大。

- 用 `+` 不是 `max`
- 每次 `% MOD`
- 空集合 / 什麼都不選算不算，base 要對
- 同一種組合不要兩條路都加到（避免雙計）

---

### 8. Bitmask

詳細：[Bitmask-DP-Thinking.md](Bitmask-DP-Thinking.md)

`k` 很小（通常 ≤20）：用一個整數 mask 的 bits 記「哪些用過」。

第 i 個用過 ↔ `(mask >> i) & 1`。  
轉移：枚舉還沒用的 bit，走到 `mask | (1<<i)`。

兩種長相：
- **DP on mask**：`f(mask, ...)` 純計數/最優
- **圖 + mask**：點是 `(節點, mask)`，邊是走路，用最短路

PDF **F**：`k≤9` 種攤販 → mask 記走過哪些種類。

---

### 9. 轉移壓縮（跳著走）

中間一大段規則相同，不必一格格 `f(i)`。

稀疏的「定死點」之間，一次跳過整個空檔。  
PDF **G**：`n≤1e15`、只有 m 個位置定死 → 定死點之間整段一起轉。

---

### 10. 矩陣轉移（是什麼）

若 `新 state = 舊 state 的線性組合`，而且同一套轉移要重複超多次：

把轉移寫成矩陣，做矩陣快速冪，`O(s^3 log n)` 一次跳 n 步。  
s = state 個數要小。G 那種超長前綴，有時會用到。先知道有這招即可。

---

### 11. Debug

- base 對不對（`f(0)`、空、不合法）
- 不可能的 state 不要當 0（最優題常要當 INF）
- 小數用純暴力對拍
- 每個維度用中文念一次：「這格到底代表什麼」

Top-down 比較少 loop-order 問題；會爆的是沒 memo、state 太大、遞迴層數。

---

### 12. 怎麼選

| 徵兆 | 走向 |
|---|---|
| 貪心會後悔 / 要計數 | DP |
| 轉移像走路、要最短 | 圖搜 |
| n 很小 | 暴力 |
| 位置上選不選 | 序列 DP |
| 容量/預算 | 背包 |
| k 很小 | bitmask |
| n 超大、中間很空 | 跳著走 / 矩陣 |

選**最簡單還能對**的那個。

## D. PDF 題目概念（不寫完整解，不寫 B）

### A 神奇樹木
從一列樹高砍掉一些，剩下非空且高度 zigzag（高低交替）。問方案數 `% 1e9+7`。

→ 序列計數 DP。TD：`f(pos, prev, higher)` = 現在走到 pos、上一個留下的高度、下一步要比它高還是低。  
你的 [A.cpp](A.cpp) 已是這棵暴力樹；`n≤2e5` 沒 memo / state 太大會爆，先求懂 state。

### C 盛夏跑堂
N×M 格子，只能往右一排，列落差 ≤ D。路徑「痛苦」= 沒噴霧格子的 min。最多 K 次噴霧（該格當 ∞）。最大化這個 min。

→ **max-min 瓶頸**。對答案二分 mid：每格 `V≥mid` 算安全，否則要花一次噴霧。再問：存不存在一條路，噴霧 ≤ K。可行性是格子 DP / BFS。

### D Deadline
n 個任務 `(deadline, cycles)`，一次跑一個。找最小整數頻率 f，使得存在順序能全部在期限內做完。`n≤5e5`。

→ 對 f 二分。固定 f 後，時間 = cycles/f，依 deadline 由早到晚排（EDF 貪心）檢查。

### E Energy
n 個來源，每個 xi≤10 個粒子；z≤10 個倍率。每源挑一個粒子，再挑一個倍率，總能量 = (粒子和)×倍率。求第 k 小。

→ 小列表相乘產生候選，求第 k 小（堆 / 二分答案+計數）。不是傳統背包。

### F 網路流
圖上 a→b。花費 = 路段數 + 相鄰攤販不同的次數 + 整路有幾種攤販。`k≤9`。

→ 圖最短路，state 要帶「上一種攤販 + 用過哪些種類」。種類用 bitmask。Dijkstra/BFS 在 `(點, last, mask)` 上走。  
詳：[Bitmask-DP-Thinking.md](Bitmask-DP-Thinking.md) · [Dijkstra.md](../Algorithms/Graph/Dijkstra.md)

### G 關卡設計
長度 n≤1e15 的序列，每格 ∈ {-1,0,1}，前綴和永遠在 `[0,1]`。m≤2e5 個位置已經定死 ±1，其餘可選。問合法填法數 `% MOD`。

→ 計數 DP，state 大概是「前綴和現在是 0 還是 1」。n 太大不能一格格走 → 定死點之間整段跳（轉移壓縮；必要時矩陣）。

### H Hamburger
n 個員工區間 `[li,ri]`，做一個堡要 t 分鐘，每人最多一個。q 筆獨立詢問：`[ql,qr]` 內能否做出 x 個。時間 1e9，n,q≤1e5。

→ 區間 + 詢問。時間先**座標壓縮**，再離線/排序處理「這個時間窗有多少人能做完」。

### I 道歉
字串長度 ≤100。`W`=做錯，`A`=道歉。立即道歉 = W 的**下一個事件**必須是 A。

→ 掃一遍模擬。不用 DP。

## 開題 10 秒

1. n 多大？小→暴力；超大→不能一格格 DP。  
2. 要最優還是計數？計數記得 MOD。  
3. 小問題掛在哪？位置 / 容量 / mask / 圖上的點。  
4. state 念得出中文再寫 `f(...)`。
