# Bitmask DP Thinking（費曼版）

> 流程：暴力 → 哪個小問題一直重複 → Top-down memo。  
> 詳解對照：[Tutorial-Quick.md](Tutorial-Quick.md) §8 · 圖上最短路見 [Dijkstra.md](../Algorithms/Graph/Dijkstra.md)

---

## 先忘掉 DP

想像 k 個開關排成一排。每個開關只有開 / 關。

一個整數 `mask` 就是這排開關：

```
bit 0 = 第 0 個用過了沒
bit 1 = 第 1 個用過了沒
...
```

例如 k=3：

| mask | 二進位 | 意思 |
|---|---|---|
| 0 | 000 | 什麼都還沒用 |
| 1 | 001 | 只用了 0 |
| 2 | 010 | 只用了 1 |
| 3 | 011 | 用了 0 和 1 |
| 4 | 100 | 只用了 2 |
| 5 | 101 | 用了 0 和 2 |
| 6 | 110 | 用了 1 和 2 |
| 7 | 111 | 三個都用了 |

不必開 `vector<bool>`。集合 = 一個 int。  
`k≤20` 才划算：`2^20 ≈ 1e6`。再大就爆。

---

## 1. 暴力（沒技巧）

k 個東西，每個「用過 / 沒用」→ `2^k` 種集合。  
若還要順序（排列），是 `k!` 條路徑。

例：3 個城市 `0,1,2`，從 0 出發，每個城市恰好走一次，邊權：

```
0—5—1
0—9—2
1—1—2
```

暴力列出哈密頓路：

- `0 → 1 → 2`：5+1 = **6**
- `0 → 2 → 1`：9+1 = 10

答案 6。k=15 這棵樹就死了。

---

## 2. 痛點

很多條路會問到同一個問題：

> 已經用過集合 S，現在站在城市 i，走完剩下的最少多少？

`S` 用 mask 表示。同一個 `(mask, i)` 被算很多次。

---

## 3. optimize：Top-down

```
f(mask, i) = 已經走訪 mask、人在 i，走完剩下城市的最小花費
```

base：`mask` 已經是全部 `(1<<k)-1` → 回傳 0（或加「回起點」的邊，看題目）。

轉移：枚舉還沒用的城市 j，

```
if (((mask >> j) & 1) == 0)
    f(mask, i) = min( f(mask | (1<<j), j) + cost[i][j] )
```

從大問題往小問：mask 只會開 bit、不會關，集合只變大。

手算（從 0 出發，開始 mask=`001`，人在 0）：

| 問誰 | 還沒用 | 結果 |
|---|---|---|
| `f(001, 0)` | 1 或 2 | min( 5+f(011,1), 9+f(101,2) ) |
| `f(011, 1)` | 只剩 2 | 1 + f(111,2) = 1+0 = 1 |
| `f(101, 2)` | 只剩 1 | 1 + f(111,1) = 1 |
| `f(111, *)` | 沒了 | 0 |

所以 `f(001,0) = min(5+1, 9+1) = 6`。跟暴力一樣。

---

## 4 個必備操作

```
測： (mask >> i) & 1        // 第 i 個開了沒
開： mask | (1 << i)        // 把第 i 個打開
關： mask & ~(1 << i)       // 把第 i 個關掉（較少用）
枚舉還沒用的：
    for(int i=0;i<k;i++)
        if(((mask >> i) & 1) == 0)
            ...
```

全部用完：`mask == (1<<k)-1`。

## 兩種長相

**純 DP：** 沒有「走在圖上」這件事，只有集合。

- `f(mask)`：用完這個集合的答案
- `f(mask, i)`：集合 + 「最後一個是誰」（TSP、相鄰限制）

**圖 + mask：** 點變成 `(u, mask)`。  
在圖上走路，順便更新 mask。這是**最短路**，不是遞迴加總。見 [Dijkstra.md](../Algorithms/Graph/Dijkstra.md)。

PDF **F**：k≤9 種攤販。mask = 這條路上出現過哪些種類。  
state ≈ `(現在路口, 上一種攤販, mask)`。

## Top-down 示意碼（3 城最短哈密頓，從 0 出發）

不當提交檔，用來對上面的手算。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int INF = 1e9;
int k = 3;
int cost[3][3] = {
    {0, 5, 9},
    {5, 0, 1},
    {9, 1, 0}
};
int dp[8][3]; // mask , last city

int f(int mask,int i)
{
    if(mask == (1<<k)-1)
        return 0;
    if(dp[mask][i] != -1)
        return dp[mask][i];
    dp[mask][i] = INF;
    for(int j=0;j<k;j++)
    {
        if(((mask >> j) & 1) == 0)
        {
            dp[mask][i] = min(dp[mask][i], f(mask|(1<<j), j) + cost[i][j]);
        }
    }
    return dp[mask][i];
}
int main()
{
    memset(dp, -1, sizeof(dp));
    cout << f(1<<0, 0); // 6
    return 0;
}
```

計數題把 `min` 換成 `+`，再 `% MOD`。base 回傳 1 不是 0。

## 什麼時候用

- k 很小（≤18～20），要記「哪些用過」
- 暴力是排列 / 子集，同一集合被問很多次

k=25 別硬上 bitmask。F 的 k≤9 剛好。
