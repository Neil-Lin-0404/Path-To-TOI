## 1. 六歲故事：排課表

學校有好幾門課。有的課要**先上完另一門**才能上。

例如：

- 要先上「認字」，才能上「讀故事」
- 要先上「讀故事」，才能上「寫作文」

老師要排出一週課表：**被要求先上的，一定排在前面。**

如果出現這種慘案：

- A 要先上 B  
- B 要先上 A  

那永遠排不出來——兩門課互相卡住。這種「轉一圈卡死」就是**環**。

**拓撲排序（Topological Sort）＝ 把有「誰要先」規則的事情，排成一條合法順序。**

排得出來 ↔ 規則裡**沒有轉圈卡死**。

---

## 2. 對應到圖的說法

把每門課想成一個**點**，把「A 要先於 B」畫成箭頭 `A → B`（先走 A，再到 B）。

| 故事 | 程式／圖論 |
|---|---|
| 課 | 點（節點） |
| 「A 要先於 B」 | 有向邊 A → B |
| 課表順序 | 拓撲序 |
| 互相卡死 | 有向環 |
| 沒有互相卡死、排得出來 | **DAG** |

**DAG**＝ Directed Acyclic Graph＝「有箭頭、但沒有轉圈」的圖。  
白話：**有方向的關係圖，而且不會繞回原點卡死。**

重要事實（記住就好）：

- 圖是 DAG ↔ **一定存在**至少一種拓撲序  
- 有環 ↔ **不存在**拓撲序（題目常要你印 `IMPOSSIBLE`）

---

## 3. 手跑小例子

四門課，規則：

```
1 → 2
1 → 3
2 → 4
3 → 4
```

意思：1 最先；2、3 都要在 4 前面。

一種合法順序：`1 2 3 4`  
另一種也合法：`1 3 2 4`  
（2 和 3 誰先都行，只要都在 4 前、都在 1 後。）

若再加 `4 → 1`，就有環 `1→…→4→1`，排不出來。

---

## 4. 方法一：Kahn（排隊解鎖）

### 六歲版

想像每門課門口掛著一塊牌子：「還要先上完幾門課才能進」。

1. 先找出牌子寫 **0** 的課（沒有先修）→ 排進課表，並排進「今天可以上」的隊伍。  
2. 上完一門課，就去告訴「以後要先修我」的那些課：「你們的先修少一門了」。牌子數字減 1。  
3. 誰的牌子變成 0，誰就可以進隊伍。  
4. 一直做到沒人可排。

如果最後排進課表的課**少於全部課數**→ 一定有人永遠解不開 → **有環**。

### 對應名詞

| 故事 | 程式 |
|---|---|
| 牌子上的數字 | **入度** `indeg[v]`＝有幾條箭頭指進來 |
| 隊伍 | `queue`（或 deque） |
| 上完課解鎖 | 對每個鄰居 `indeg[v]--`，變 0 就入隊 |
| 排進課表的人數 | `order.size()`；`< n` 就有環 |

### 為什麼叫 Kahn？

這是一種經典寫法：用「入度 + 佇列」做拓撲排序。比賽裡很好寫、也好判環。

### 大概要做多久？

每條邊、每個點大概看常數次 → 約略「跟點數＋邊數成正比」（`O(n + m)`），外加讀入。

## 5. 方法二：DFS（鑽到底再記下來）

### 六歲版

從一門課開始，一直往「之後才能上的課」鑽，鑽到沒路了，**出來時把自己的名字記在紙上**。全部鑽完後，**把紙從後面往前念**——那就是一種拓撲序。

（直覺：越晚才能上的課，越早被「鑽到底」記下來；倒過來念，先修的就在前面。）

### 一定要先找有沒有環

如果有環，光「記下來倒著念」會騙人。要用**三色**（或灰／黑）：

- 還沒去過  
- 正在鑽（還在路上）  
- 鑽完了  

若走到「正在鑽」的課 → 發現自己繞回來了 → **有環**。

這和 CSES Round Trip II（有向找環）是同一套感覺。

### 和 Kahn 怎麼選？

| | Kahn | DFS |
|---|---|---|
| 直覺 | 解鎖排隊 | 鑽到底再倒序 |
| 判環 | 排出來的人數 `< n` | 走到「正在鑽」的點 |
| 實作 | 入度 + queue，常較直覺 | 遞迴／顯式棧，注意爆棧 |
| 輸出 | 入隊順序就是一種拓撲序 | 完成順序要 reverse（或頭插） |

比賽題「排課／依賴」→ **Kahn 通常最好寫**。

## 6. 常見坑

1. **邊的方向反了** — 題目若寫「上完 a 才能上 b」，邊是 `a → b`（a 在前）。搞反整張序都錯。  
2. **有環仍輸出序** — 必須檢查 `order.size() == n`（Kahn）或三色（DFS）。  
3. **不連通** — 好多堆課互不相干：Kahn 一開始把所有入度 0 的都入隊；DFS 要對每個還沒去過的點開搜。  
4. **只要任一合法序** — 不用找「字典序最小」，除非題目特別要求（那就把 queue 換成 priority_queue）。

## 7. 模板（Kahn）

見 [TopologicalSort.cpp](TopologicalSort.cpp)。核心：

```cpp
// 邊 a → b：a 必須排在 b 前面
vector<int> indeg(n + 1, 0);
for (/* 每條邊 a→b */) {
    graph[a].push_back(b);
    indeg[b]++;
}
queue<int> q;
for (int i = 1; i <= n; i++)
    if (indeg[i] == 0) q.push(i);

vector<int> order;
while (!q.empty()) {
    int u = q.front(); q.pop();
    order.push_back(u);
    for (int v : graph[u]) {
        if (--indeg[v] == 0) q.push(v);
    }
}
if ((int)order.size() != n) { /* IMPOSSIBLE */ }
```

## 8. 帶走

1. 拓撲序＝遵守「誰先誰後」的排隊；有環就排不成。  
2. **DAG**＝有箭頭但沒有環 ↔ 存在拓撲序。  
3. **Kahn**＝入度 0 的先排，排完解鎖鄰居；人數不夠＝有環。  
4. DFS 要搭配「正在路上」的顏色才能穩判環。  
5. 下一站：在 DAG 上做 DP（最長路、路徑數）——先會排拓撲序，再依序更新。
