## 1. 六歲故事：幫村莊修路

有好幾個村莊。每兩村之間「可以」修一條路，但每條路有**價錢**。

市長說：

1. 最後要讓**任意兩村都能互相到達**（可以繞路）。  
2. 總價錢要**盡量便宜**。  
3. 不要修多餘的路——如果兩村已經通了，再修一條只會多花錢，還可能圍成沒必要的圈。

最後選出來的那些路，連起來會長得像一棵「樹」：有連通、沒有圈。  
在圖論裡這叫**生成樹**；總價錢最小的那棵叫 **MST（Minimum Spanning Tree）＝ 最小生成樹**。

---

## 2. 對應到圖的說法

| 故事 | 程式／圖論 |
|---|---|
| 村莊 | 點 |
| 可選的路＋價錢 | 無向邊＋邊權 |
| 全部連起來 | 連通 |
| 不要圍圈 | 無環 |
| 連通又無環的邊集合 | 生成樹（n 個點正好 n−1 條邊） |
| 總價錢最小的生成樹 | **MST** |

前提：圖是**無向、連通、有邊權**。（若不連通，沒有生成樹；題目常要你判斷。）

---

## 3. 為什麼可以「貪心」？（六歲版切分）

把村莊先想像成兩堆：已經通電的／還沒通電的。

**兩堆之間，最便宜的那一座橋，一定可以修進「最便宜總方案」裡。**  
（若你不修它、改修更貴的，總價只會更差或一樣。）

這句話撐起下面兩種算法——它們只是「挑最便宜邊」的兩種排隊方式。

## 4. Kruskal：從最便宜的路開始修

### 六歲版

1. 把所有「可能的路」依照價錢**從小到大排好**。  
2. 依序看每一條：  
   - 若這條路連的兩個村**已經通了** → 跳過（會圍圈、浪費錢）。  
   - 若**還沒通** → 修好它，兩個村（兩團）合併成一團。  
3. 修到只剩一大團（或已修滿 n−1 條）就結束。

「兩個村已經通了嗎？」→ 用 **DSU（並查集／小組長）** 問「同一組嗎」。詳見 [DSU.md](../../Data_Structure/DSU.md)。

### 手跑

村莊 1,2,3,4。路（價錢）：

```
1-2:1
1-3:4
2-3:2
2-4:5
3-4:3
```

排序後：`1-2(1)` → `2-3(2)` → `3-4(3)` → `1-3(4)` → `2-4(5)`

| 看哪條 | 同一組？ | 動作 |
|---|---|---|
| 1-2 | 否 | 修；合併 |
| 2-3 | 否 | 修；合併（1,2,3 一團） |
| 3-4 | 否 | 修；合併（全通） |
| 1-3 | 是 | 跳過 |
| 2-4 | 是 | 跳過 |

MST 邊：`1-2, 2-3, 3-4`，總價 `1+2+3=6`。

### 大概要做多久？

主要花在**把邊排序**：邊很多時，排序主導時間（約 `O(m log m)`）。  
DSU 每次合併／詢問幾乎一下下。

## 5. Prim：從一個村慢慢長出去

### 六歲版

1. 先隨便選一個村，標成「已接通」。  
2. 看所有「一端已接通、一端還沒」的路，挑**最便宜**的那條修下去，把新村標成已接通。  
3. 重複，直到所有村都接通。

像在雪地裡從一間小屋開始鋪路，每次只往外接最近的一間。

### 和 Dijkstra 的感覺

Prim（用堆加速時）很像 Dijkstra：都是「每次拿目前最好的候選」。  
差在：Dijkstra 更新的是「到起點的路程」；Prim 更新的是「接到樹上的那條邊有多便宜」。

### 大概要做多久？

用堆實作時，大約跟「點＋邊、再乘一點 log」有關（`O((n+m) log n)` 量級）。  
點少邊超多時，有時 Kruskal（排序）反而更直覺；實務看資料與你熟哪招。

## 6. Kruskal vs Prim

| | Kruskal | Prim |
|---|---|---|
| 故事 | 全球最便宜的路依序考慮 | 從一點往外長 |
| 需要 | 排序 + DSU | 堆（或稠密圖用陣列） |
| 圖不連通 | DSU 最後組數 > 1 可知 | 有點永遠接不進來 |
| 像誰 | 「邊為主」 | 「點為主」，像 Dijkstra |

競賽默寫：**Kruskal + DSU** 常常最短、最好除錯。

---

## 7. 常見坑

1. **當成有向圖** — MST 標準設定是無向；邊存成 `{u,v,w}` 即可。  
2. **忘記判連通** — 加完邊後若連通分量 > 1，沒有 spanning tree。  
3. **Kruskal 沒跳過同組** — 會圍圈，不是樹。  
4. **邊權可以是 0／負** — MST 貪心仍可（與最短路不同）；照樣排序／取最小。

## 9. 帶走

1. MST＝用最便宜的總價把全部村莊連起來，且不要多餘的圈。  
2. **Kruskal**＝邊由便宜到貴；同組就跳過（DSU）。  
3. **Prim**＝從一點長樹，每次接最便宜的外緣邊。  
4. 先會 DSU，Kruskal 幾乎是送分題。
