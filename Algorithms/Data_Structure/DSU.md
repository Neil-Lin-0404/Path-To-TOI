## 1. 六歲故事：小組長

教室裡很多小朋友。老師偶爾會說：

- 「小明那一組跟小華那一組併成一組。」  
- 「小美跟小強現在同一組嗎？」

每個組有一個**小組長**。問「同一組嗎」＝問「你們的小組長是不是同一個人」。

合併兩組＝讓其中一個組長去認另一個當新組長（兩組合成一組）。

**DSU（Disjoint Set Union）＝ 並查集**  
就是專門幫你維護「誰跟誰同一團」的工具：會**查**、會**併**。

---

## 2. 對應到程式

| 故事 | 程式 |
|---|---|
| 每個小朋友 | 一個編號 `1..n` |
| 小組長 | 根（root）：`parent[x] == x` 的那個 |
| 「我的組長是誰」 | `find(x)` |
| 兩組合併 | `unite(a, b)` |
| 是否同組 | `find(a) == find(b)` |

一開始：每個人自己當自己的組長（`parent[i] = i`）。

---

## 3. 找組長：一路問上去

小明說：「我的上級是小花。」  
小花說：「我的上級是組長阿明。」  
阿明說：「我就是組長。」

`find` 就是一路問到「上級是自己」的人。

### 抄近路（路徑壓縮）

小明問完後可以改口：「我直接認阿明當上級。」  
下次就不用再問小花。

程式裡常見寫法：

```cpp
int find(int x) {
    return parent[x] == x ? x : parent[x] = find(parent[x]);
}
```

意思：找到根之後，順便把路上的人都改成直接掛在根下面。

---

## 4. 合併：小組合進大組

兩組合併時，比較好的習慣是：**人少的那組，去認人多的那邊組長**。  
（樹比較矮，之後比較好找。）

這叫 **union by size**（按大小）或 **union by rank**（按大約高度）。  
比賽裡用 size 就很好記。

```cpp
bool unite(int a, int b) {
    a = find(a); b = find(b);
    if (a == b) return false;   // 本來就同組
    if (sz[a] < sz[b]) swap(a, b);
    parent[b] = a;
    sz[a] += sz[b];
    return true;                // 成功合併
}
```

## 5. 手跑

人：1 2 3 4。一開始各自一組。

| 操作 | 結果（誰跟誰同組） |
|---|---|
| unite(1,2) | {1,2} {3} {4} |
| unite(3,4) | {1,2} {3,4} |
| same(1,2)? | 是 |
| same(1,3)? | 否 |
| unite(2,3) | {1,2,3,4} 全同一團 |
| same(1,4)? | 是 |

Kruskal 修路時：若 `unite` 回傳 `false`，表示兩村已通 → 這條路跳過。

## 6. 為什麼說「幾乎一下下就好」？（Ackermann 故事）

### 六歲版

想像有一種數，長大的方式**超誇張**：

- 不是 +1、+1  
- 也不是一直 ×2  
- 而是「疊了又疊」那種兇法——紙都寫不下

這種兇法有個名字叫 **Ackermann（阿克曼）函數**。你**不必會算它**。只要知道：它大到嚇人。

現在問反過來的問題：

> 「要輸入多大的 n，這個兇函數才會變大一點點？」

答案是：n 要大到宇宙等級，它才慢慢加 1。  
這個「反過來」叫 **反阿克曼函數 α(n)**（inverse Ackermann）。

**α(n) 長得很慢很慢。**  
實務上，點數就算多到 `10^18`，α(n) 還是一個很小的數字（常常想成 ≤ 4）。

### 跟 DSU 有什麼關係？

理論家證明：如果你同時做

- 找組長時抄近路（路徑壓縮）  
- 合併時小組合進大組（按 size／rank）  

那平均每次 `find`／`unite` 的成本，大約跟 α(n) 一樣——也就是**幾乎是常數次動作**。

所以競程口頭禪：

> DSU 操作「幾乎 O(1)」。

你**不用在程式裡算 Ackermann**；只要把壓縮 + 按大小寫對即可。

### 選讀：Ackermann 有多兇（可跳過）

其中一種常見定義會讓數字暴衝（示意，不必背）：

- 一層像一直加  
- 再一層像一直乘  
- 再一層像一直「自己的指數塔」  

重點仍是：正的很兇 → 反的 α(n) 幾乎不動 → DSU 很快。

## 7. 常見坑

1. **`unite` 前沒 `find`** — 必須先找到兩邊真正的組長再掛。  
2. **路徑壓縮寫錯** — `parent[x] = find(parent[x])` 要回傳根。  
3. **用 DSU 當有向關係** — 標準 DSU 管的是「無向同組」；有向依賴請看拓撲。  
4. **忘記初始化** — `parent[i]=i`，`sz[i]=1`。
